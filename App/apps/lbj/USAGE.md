# LBJ 使用说明（固件版 + App 版）

> 对应 **v0.19** 起的 Fusion 固件，以及 LBJ RX overlay（app 行为自 v0.7 起未变）。

---

## 0. 一分钟看懂

|  | **固件版**（常驻功能） | **App 版**（LBJ RX overlay） |
|---|---|---|
| 装什么 | 什么都不用装，刷 Fusion 固件就有 | 把 `lbj.bin` 装进一个 app 槽位 |
| 怎么进 | 信道**调制设成 LBJ**，频率 821.2375 MHz | 频率、调制模式不用管，直接进 **F4HWN APPS → LBJ RX** |
| 解出报文 | 自动弹全屏窗口 | 进 app 后一直显示 |
| 历史条数 | **1024 条**（写外部 flash，掉电不丢） | 8 条（RAM，退出即丢） |
| 能导出吗 | **能**：K 头写频线 + 网页/Python 导出 CSV | 不能（只看） |
| 适合 | 长期守台、事后对账、存档导出 | 现场看车、看车型/线路/距离 |

---

## 1. 频率与调制（两个版本不一样！）

| 版本 | 频率 | 调制方式 | 说明 |
|---|---|---|---|
| 固件版 | **821.2375 MHz** | **LBJ** | LBJ 是"只收"的独立模式，调频/带宽由固件自己管 |
| App 版 | **不用管** | **不用管** | app 自己采 PA4 音频解调；带 `pin` 的工件进入时自动钉到 821.2375 MHz |

> 调制方式在**信道编辑**里改（和 FM / AM / RAW 同一个列表）。VFO 直接改也行，但存进
> 信道更省事。

# 一、固件版

## 2. 开始使用（三步）

1. 选一个信道（MR 或 VFO）：**调制方式 → LBJ**，频率 **821.2375 MHz**。
2. 要留档才需要，否则保持OFF：菜单 → **`LBJLOG`** → **`ON`**。
3. 守着就行。解出一条报文会自动弹出解码窗口；窗口内容同时由 LED 提示（见 §5）。

## 3. 屏幕说明

弹出窗口占满主区，最上面一行状态栏保持固件原样（电池、图标等），不画标题和频率。

```
K412 DN              12.3km      ← ① 车次 + 方向 + BCH 标记 | 右侧：距离
SPD 87 km/h                      ← ② 速度
KM 0344.7                        ← ③ 公里标
HXD1C 23900050                   ← ④ 车型缩写 + 8 位机车登记号
LINE JHX                         ← ⑤ 线路（拼音首字母）
1234002 -87dB                    ← ⑥ 解出的地址值 + 接收瞬间的信号强度
1/8          12s          EXIT   ← 底栏：第几条/共几条 | 多久以前 | EXIT=关窗
```

逐行解释：

| 行 | 含义 | 何时出现 |
|---|---|---|
| ① | 车次前缀（K/T/D/C…）+ 车次 + 方向（`DN` 下行 / `UP` 上行 / 未知不显示） | 总是 |
| ① | **BCH 标记**：什么都没 = 干净；`*` = 有码字被纠正过；`!` = 有码字纠不回来（`!` 优先） | 仅当需要时 |
| ①右 | **距离**：`12.3km`；`--km` = 有详情块但位置无效/没设位置；`>999km` = 太远 | 只有带详情块的报文才有 |
| ② | 速度（`-` = 没解出来，不会显示假的 0） | 短报文/合并报文 |
| ③ | 公里标 `DDDD.D`（`-` 同上） | 同上 |
| ④ | 车型英文缩写 + 8 位登记号（3 位车型码 + 5 位车号）；短报文显示 `-------` | 详情块 |
| ⑤ | 线路名的拼音首字母（京沪线 → `JHX`），二级字库显示 `?`；没有则 `LINE -` | 详情块 |
| ⑥ | 解出的 POCSAG 地址（1 234 001/002 是预警、1 233 999/4000 是基础预警）+ 接收强度（小字，不是实时值） | 总是 |
| 底 | `当前/总数`、`多久以前`（`12s` / `3m05s` / `99m+`）、`EXIT` | 总是 |

> 一辆车一条：同一次列车的"短块"和"详块"会合并进同一条记录，不会变成两条。

## 4. 按键

窗口打开时**独占键盘**，只有这几个键有用：

| 键 | 作用 |
|---|---|
| **UP / DOWN** | 翻历史（最新 → 更旧），到两头就停；按住不会连发 |
| **EXIT** | 关窗。这次载波内不再自动弹（下一段载波会重新自动弹） |
| **PTT** | 关窗、停采样，正常发射 |

其余按键被窗口吃掉（不会误改设置）。窗口关掉后一切照旧。

## 5. LED 与背光（v0.18 起）

| 情况 | 表现 |
|---|---|
| 只有载波、还没解出报文 | **绿灯常亮**（B 通道绿+红）——就是普通的"有信号"灯 |
| 解出一条新报文 | **闪 2 下**（灭 100 / 亮 100 / 灭 100 / 亮 100 ms），一辆车只闪一次 |
| 新报文 | 顺带点亮背光 |

> 非 LBJ 通道、发信红灯、`SetEOT` 收尾闪灯都保持原样，不受影响。

## 6. 菜单项

菜单里和 LBJ 有关的四项（在设置菜单靠后的位置）：

| 菜单项 | 取值 | 作用 |
|---|---|---|
| **`LBJMSG`** | —（动作） | 手工打开解码窗口，显示最新一条。<br>还没解出过任何报文时不会打开，菜单停在原处 |
| **`LBJPOP`** | `ON` / `3s` / `5s` / `10s` / `60s` | 报文**自动**打开的窗口，在最后一次报文/按键之后多久自己关掉。<br>`ON` = 不自动关（按 EXIT 或 PTT 才关）。**手工**用 `LBJMSG` 打开的窗口永远不自动关 |
| **`LBJLOG`** | `OFF` / `ON` | 每解出**一辆车**就往 flash 写一条（32 字节）。默认 `OFF`：不开就什么也不写，导出也不会有数据 |
| **`LBJCLR`** | `No` / `Yes` | 清空日志。默认 `No`，只有明确选 `Yes` 才清；清空在后台按扇区慢慢擦，不卡收音 |

日志容量与行为：

- 区域 `0x018000..0x01FFFF`，**32 KiB = 1024 条 × 32 字节**。
- 写满后**从头覆盖最旧的**（环形），所以永远保存最近 1024 辆车。
- 一辆车的记录在它**最后一串报文安静 10 秒后**才落盘 —— 车刚过去时立刻读，可能还差这一条。

**快捷键（v0.19 起）**：不想进菜单的话，可以把 `LBJMSG` 挂到按键上 —— 设置菜单里的
**`F1Shrt` / `F1Long` / `F2Shrt` / `F2Long` / `M Long`** 任一项，动作选成 **`LBJMSG`**，
之后按那个键（侧键 1 / 侧键 2 短按或长按、长按 M）就等于菜单项 `LBJMSG`：打开解码窗口
显示最新一条。

- 和菜单项打开的一样是**手工打开**，**不受 `LBJPOP` 自动关闭影响**，按 EXIT 或 PTT 才关。
- 还没解出过任何报文时**不打开、双响**；发射中和 FM 收音机模式下同样双响拒绝。
- 在菜单/设置里按、键盘锁着按都能用（会先像 EXIT 那样退出菜单再弹窗）。
- 已存好的按键设置不会因为升级而改变，要自己把那一项选成 `LBJMSG`。

# 二、App 版（LBJ RX overlay）

## 7. 安装与进入

1. 下载 CI 的覆盖层工件（二选一，见 §16 的变体表）：
   `overlay-apps`（英文）/ `overlay-apps-cn`（中文）变体。
2. 电台进入 **F4HWN APPS**（app 选择器），用 **UV Studio** 把 `lbj.bin` 写进任意空槽位。
   选择器会自动发现新写入的槽（不用重启）。
3. 在 **F4HWN APPS → LBJ RX** 里启动。

## 8. 屏幕说明

顶部 1 行状态栏 + 主区 7 行（状态栏同样是固件原样）。

**SUM 页（解析摘要）**

```
K412 DN                           ← 车次前缀+车次+方向（粗体），末尾 BCH 标记 * / !
SPD 87 km/h                       ← 速度（无效显示 -）
KM 0344.7                         ← 公里标（无效显示 -）
HXD1C 23900050                    ← 车型英文缩写 + 8 位登记号（短报文：-------）
LINE JHX                          ← 线路；中文版构建显示原样汉字
1234002 -87dB                     ← 地址 + 接收强度（小字）
4BL:OFF 1SPK:ON 1/3               ← 底栏：4=背光常亮、1=扬声器、当前/总数
```

- 中文版（`LBJ_ROUTE_CN`）多了键 `5` 切中/英，线路行显示原样汉字。

## 9. 按键

| 键 | 作用 |
|---|---|
| **UP / DOWN**（UV-K1 用左右） | 选更新 / 更旧的记录（最多 8 条） |
| **`1`** | 扬声器开/关（默认关，每次进入都重置） |
| **`2`** | 清空报文历史 |
| **`4`** | 背光常亮 / 自动熄灭（仅本次运行） |
| **`5`** | 中/英显示切换（**仅中文版** `LBJ_ROUTE_CN`） |
| **EXIT** | 退出，回 Apps 菜单 |

# 三、LBJ Edit：经纬度（"距离"从哪来）

## 11. 它是什么

固件版第 ① 行右边的**距离**，需要知道**你在哪**。LBJ Edit 就是填这个位置的小 app：
存 **5 个位置**，选一个当 **PRIMARY**（测量点），固件版的弹窗就用它算距离。

> 它不是用来改 APRS 的：位置存在 app 自己的配置区，不碰 APRS TX profile 的
> 信标内容。删掉这个 app，固件版会退回去用 APRS Edit 里 TX profile 的位置。

### 11.1 屏幕

```
┌─────────────────────────────────────┐
│           LBJ EDIT                  │  标题
│ LAT 1                               │  ▶ 菜单：每个槽位一个纬度、一个经度，
│ LON 1*                    30 35.16  │    最后一项 PRIMARY
│ LAT 2                               │    "*" = 固件正在用这个槽位
│           01/11                     │  当前/总数
│ MENU=EDIT EXIT=SAVE                 │  键提示（编辑时显示输入校验结果）
└─────────────────────────────────────┘
```

### 11.2 按键

| 键 | 作用 |
|---|---|
| **UP / DOWN**（UV-K1：LEFT / RIGHT） | 选条目；停在 `PRIMARY` 时依次是 `--`（不指定）/ 1 / 2 / 3 / 4 / 5 |
| **MENU** | 打开选中的坐标进入编辑；在编辑器里再按 = **保留**这次修改 |
| **`0`–`9`** | 编辑器里：写入光标处的数字并自动前进 |
| **EXIT** | 编辑器里 = **撤销**这个字段（回到进来时的样子）；在菜单上 = **保存并退出** |

> 打开坐标时会先快照整个存储：EXIT 撤销、MENU 保留。只改过才会写 flash（只是进去看看
> 不会动任何东西）。

### 11.3 输入格式（只有北纬 / 东经）

一个槽位 = **13 位数字**：

| 字段 | 位数 | 例 | 含义 |
|---|---|---|---|
| 纬度 | 6 | `30 35 16` | 度 `DD`、分 `MM`、百分之几分 `hh` → 北纬 30°35.16′ |
| 经度 | 7 | `104 16 10` | 度 `DDD`、分 `MM`、百分之几分 `hh` → 东经 104°16.10′ |

- 分辨率 0.01′ ≈ **18.5 m**，远小于弹窗显示的 0.1 km，够用。
- 只支持**北纬、东经**（和 APRS Edit 的字段一致）。
- 没填过的槽位显示成横杠，填坏的数字（不在 0-9 / 分钟 ≥60 / 经度首位 >1）会被拒绝。

### 11.4 把哪个位置当测量点

1. 在菜单里选 **`PRIMARY`**，用 UP/DOWN 选 **1…5**。
2. 想**取消**（让固件改用 APRS TX profile 的位置）：把 `PRIMARY` 选成 **`--`**。
3. 选中的槽位会打 `*`；PRIMARY 指向没填过的槽位时，固件同样退回 APRS TX profile。

### 11.5 "距离"的取值顺序

1. **LBJ Edit 的 PRIMARY**（填了且合法）→ 用它；
2. 否则用 **APRS Edit 里 TX profile** 的位置；
3. 都没有，或这条报文没有详情块 → 第 ① 行右侧显示 `--km`（有详情块但位置无效）或什么都不显示（没详情块）。

# 四、导出（车次日志 → CSV / Excel）

**前提**：菜单里 `LBJLOG` = `ON`，并且解出过车。

**连接线**：目前请用 **K 头写频线**（USB 转串口）。USB-C 直连的读取还有一个待修问题，
在它修好之前用 K 口。

## 12. 网页版（推荐，不用装 Python）

1. 打开页面：https://lbj.xanyi.eu.org
2. 浏览器用**桌面版 Chrome / Edge**（Web Serial）。
3. 点 **连接** → 选串口 → 点 **读取**（进度条走 32 KiB，256 × 128 字节）。
4. 读到后：表格上方有**筛选框**，**下载 CSV**（Excel 直接打开）、**下载 .bin**（原始 32 KiB 存档）。
5. 报错会直接显示在日志区（例：`错误：Read failed at 0x18000`）。

## 13. Python 版

```
python tools/lbj_log.py --list                        # 列出串口
python tools/lbj_log.py --port COM3                   # 读到终端并打印表
python tools/lbj_log.py --port COM3 -o lbj.csv        # 存 CSV（英文表头）
python tools/lbj_log.py --port COM3 --chinese -o 车次.csv   # 中文表头
python tools/lbj_log.py --port COM3 --raw zone.bin    # 只存原始 32 KiB
python tools/lbj_log.py --port COM3 --clear           # 清空日志（危险，见下）
```

| 选项 | 说明 |
|---|---|
| `--port` | 串口名，如 `COM3` / `/dev/ttyUSB0`；省略则自动选第一个 |
| `--baud` | 波特率，默认 **38400** |
| `-o/--out` | 输出 CSV 文件名（默认只打印到终端） |
| `--chinese` | CSV 表头用中文 |
| `--raw FILE` | 只把 32 KiB 原始区存成文件，不解析 |
| `--clear` | **清空**车次日志（会擦除整个区域） |
| `--list` | 列出可用串口后退出 |
| `--dry-run` | 只显示将要做什么，不真读 |
| `--debug` | 打印收发帧（排查用） |

## 14. CSV 字段

列顺序（`--chinese` 时为中文表头）：

| 列 | 中文表头 | 含义 | 未知时 |
|---|---|---|---|
| `seq` | 序号 | 记录序号（固件写入顺序，从 0 起） | — |
| `uptime_s` | 运行时间 | 写入时电台开机秒数（16 位，约 18 小时回绕） | — |
| `train` | 车次 | 车次数字（前缀 K/T/D/C 见下） | 空 |
| `direction` | 上行下行 | `DN` 下行 / `UP` 上行 | 空 |
| `speed_kmh` | 速度 | 整数，km/h | 空 |
| `km_post` | 公里标 | 一位小数，km | 空 |
| `model` | 车型 | 车型英文缩写（如 `HXD1C`） | 空 |
| `loco_number` | 车号 | 8 位机车登记号（3 位车型码 + 5 位车号） | 空 |
| `route` | 线路 | 线路名拼音首字母（如 `JHX`） | 空 |
| `distance_km` | 距离 | 一位小数，km（按接收那一刻算） | 空 |

- 车次**前缀**（K/T/D/C）来自详情块，固件在弹窗里拼在车次前；CSV 的 `train` 只有数字。
- 一行 = 一辆车（同车的短块/详块已合并）。
- 空单元格 = 这条报文没带该字段，或该码字坏了 —— 不是 0。
