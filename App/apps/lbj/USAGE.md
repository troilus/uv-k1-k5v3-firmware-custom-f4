# LBJ 使用说明（固件版 + App 版）

> 对应 **v0.23** 起的 Fusion 固件，以及 LBJ RX overlay（app 行为自 v0.7 起未变）。

---

## 0. 一分钟看懂

|  | **固件版**（常驻功能） | **App 版**（LBJ RX overlay） |
|---|---|---|
| 装什么 | 什么都不用装，刷 Fusion 固件就有 | 把 `lbj.bin` 装进一个 app 槽位 |
| 怎么进 | 信道**调制设成 LBJ**，频率 821.2375 MHz | 频率、调制模式不用管，直接进 **F4HWN APPS → LBJ RX** |
| 解出报文 | 自动弹全屏窗口 | 进 app 后一直显示 |
| 历史条数 | **1024 条**（写外部 flash，掉电不丢） | 8 条（RAM，退出即丢） |
| 在电台上看 | **能**：菜单项 `LBJHST`，一屏 5 条（也可连电脑导出） | 能，app 内单条翻看 |
| 测距的坐标 | **菜单里直接填**：`LBJPRI` / `LBJLAT` / `LBJLON`（v0.22 起，见 §6.3） | 用固件版菜单填（app 自己不填坐标） |
| 能导出吗 | **能**：K 头写频线 + 网页/Python 导出 CSV | 不能（只看） |
| 适合 | 长期守台、事后对账、存档导出 | 现场看车、看车型/线路/距离 |

---

## 1. 频率与调制（两个版本不一样！）

| 版本 | 频率 | 调制方式 | 说明 |
|---|---|---|---|
| 固件版 | **821.2375 MHz** | **LBJ** | LBJ 是"只收"的独立模式，调频/带宽由固件自己管 |
| App 版 | **不用管** | **不用管** | app 自己采 PA4 音频解调；带 `pin` 的工件进入时自动钉到 821.2375 MHz |

> 调制方式在**信道编辑**里改（和 FM / AM / RAW 同一个列表）。VFO 直接改也行，但存进
> 信道更省事。

# 一、固件版

## 2. 开始使用（三步）

1. 选一个信道（MR 或 VFO）：**调制方式 → LBJ**，频率 **821.2375 MHz**。
2. 要留档才需要，否则保持OFF：菜单 → **`LBJ`** 分类 → **`LBJLOG`** → **`ON`**
   （菜单怎么走见 §6.1）。
3. 守着就行。解出一条报文会自动弹出解码窗口；窗口内容同时由 LED 提示（见 §5）。
4. 想在**电台上**看存下来的车次：菜单 → **`LBJ`** → **`LBJHST`**（一屏 5 条，见 §3 / §4）；
   要导出成 CSV / Excel 用电脑读，见 §12 / §13。
5. 想让窗口第 ① 行右边显示**距离**：先填一次自己的坐标 —— 菜单 → **`LBJ`** →
   **`LBJPRI`** 选一位（`1`…`5`），再用 **`LBJLAT`** 填纬度、**`LBJLON`** 填经度
   （怎么填见 §6.3）。填一次就一直在，掉电不丢。

## 3. 屏幕说明

弹出窗口占满主区，最上面一行状态栏保持固件原样（电池、图标等），不画标题和频率。

```
K412 DN              12.3km      ← ① 车次 + 方向 + BCH 标记 | 右侧：距离
SPD 87 km/h                      ← ② 速度
KM 0344.7                        ← ③ 公里标
HXD1C 23900050                   ← ④ 车型缩写 + 8 位机车登记号
LINE JHX                         ← ⑤ 线路（拼音首字母）
1234002 -87dB                    ← ⑥ 解出的地址值 + 接收瞬间的信号强度
1/8          12s          EXIT   ← 底栏：第几条/共几条 | 多久以前 | EXIT=关窗
```

逐行解释：

| 行 | 含义 | 何时出现 |
|---|---|---|
| ① | 车次前缀（K/T/D/C…）+ 车次 + 方向（`DN` 下行 / `UP` 上行 / 未知不显示） | 总是 |
| ① | **BCH 标记**：什么都没 = 干净；`*` = 有码字被纠正过；`!` = 有码字纠不回来（`!` 优先） | 仅当需要时 |
| ①右 | **距离**：`12.3km`；`--km` = 有详情块但位置无效/没设位置（坐标怎么填见 §6.3）；`>999km` = 太远 | 只有带详情块的报文才有 |
| ② | 速度（`-` = 没解出来，不会显示假的 0） | 短报文/合并报文 |
| ③ | 公里标 `DDDD.D`（`-` 同上） | 同上 |
| ④ | 车型英文缩写 + 8 位登记号（3 位车型码 + 5 位车号）；短报文显示 `-------` | 详情块 |
| ⑤ | 线路名的拼音首字母（京沪线 → `JHX`），二级字库显示 `?`；没有则 `LINE -` | 详情块 |
| ⑥ | 解出的 POCSAG 地址（1 234 001/002 是预警、1 233 999/4000 是基础预警）+ 接收强度（小字，不是实时值） | 总是 |
| 底 | `当前/总数`、`多久以前`（`12s` / `3m05s` / `99m+`）、`EXIT` | 总是 |

> 一辆车一条：同一次列车的"短块"和"详块"会合并进同一条记录，不会变成两条。

**日志列表页（菜单 `LBJHST`，或在窗口里按 `MENU`，v0.20 起）**

解码窗口的第二页：直接在电台上看 flash 里存的车次记录，不用连电脑。

```
   1 K412      87  12.3     ← 选中行整行反白
   2 HXD1C    102  45.0
   3 D5         -     -     ← 缺的字段画横杠，不会显示假的 0
   4 1234     120  99.9
   5 T7         -  >999     ← `>999` = 太远
LOG 57                     ← 一共存了多少条
 MENU DETAIL        EXIT CLOSE  ← MENU=看选中那条详情 / EXIT=关窗
```

| 列 | 含义 |
|---|---|
| 序号 | **1 = 最新**往下数（和底部总数同一套）；导出 CSV 的 `seq` 在详情页 |
| 车次 | 带类型前缀（`K412`）；这条没带就是 `--` |
| 速度 | km/h，`-` = 这条没带 |
| 距离 | km，一位小数；`>999` = 太远，`-` = 这条没带 |

详情页和实时页**逐行一致**，只有第 6 行不同：实时页是解出的地址值和接收强度，记录里
没有这两样，这里改成 **`#序号`**（导出 CSV 的 `seq` 列）和**写入时刻** `T+时:分:秒`
（记录里没有时钟，就是开机秒数）。底栏是它在列表里的位置（`3/57`）。

> 打开列表时会先确认 flash 里有多少条；日志为空、或 `LBJCLR` 正在清空时**不打开**。
> 列表里的条数在打开那一刻固定，浏览期间新写入的记录不会把视图拽走（重开列表即刷新）。

## 4. 按键

窗口打开时**独占键盘**，只有这几个键有用：

| 键 | 作用 |
|---|---|
| **UP / DOWN** | 实时页：翻 RAM 里的 8 条历史（最新 → 更旧），到两头就停<br>列表页：上下移动选中行（走到屏幕上下边缘时列表跟着滚）<br>详情页：直接翻上一条 / 下一条**存盘**记录 |
| **MENU** | 切页：实时页 → **日志列表**；列表 → 选中那条的**详情**；详情 → 回列表 |
| **EXIT** | 关窗（在列表页和详情页也一样，一下到底）。这次载波内不再自动弹（下一段载波会重新自动弹） |
| **PTT** | 关窗、停采样，正常发射 |

其余按键被窗口吃掉（不会误改设置）；按住不会连发，按一下走一条。窗口关掉后一切照旧
（主界面上 `EXIT` 短按切单双信道，v0.22 起改成**松手**才动作：按久了只恢复 VFO，
用它关窗口的那一下也不会顺手切换）。

> 新报文**不会打断浏览**：窗口开着时列表 / 详情 / 正在翻的历史都停在原处；关掉窗口后
> 新报文才重新自动弹到最新一条。

## 5. LED 与背光（v0.18 起）

| 情况 | 表现 |
|---|---|
| 只有载波、还没解出报文 | **绿灯常亮**（B 通道绿+红）——就是普通的"有信号"灯 |
| 解出一条新报文 | **立刻闪 4 组、共 8 下**（v0.22 起）：组内亮 100 / 灭 100，组间灭 500，一共 3.2 秒 |
| 新报文 | 顺带点亮背光 |

> 闪的就是普通信道"载波消失"那套闪灯（4 组 × 2 下），只是**不等那 1 秒**，收到报文立刻开始；
> 一辆车只闪一组。非 LBJ 通道、发信红灯、`SetEOT` 收尾闪灯都保持原样，不受影响。

## 6. 菜单与分类

### 6.1 分类菜单（v0.21 起；v0.22 起分类页只有一行，v0.23 起邻居在上面那行）

设置菜单分**两级**：按 `M` 先进**分类页**，选中分类再按一次 `M` 才进到设置项列表。

```
  < 扫描                      全部 >     ← 上面一行：上一类 / 下一类（各带一个箭头）
  [         信道         ]                ← 中间反白的就是当前分类（和列表高亮同一行）
              19                          ← 名称下面：这个分类有几项
                              2/12        ← 最底行右下角：第几个分类 / 共几个
```

- 上一类在**上面那一行的左边**、下一类在**右边**，都带箭头（`<` `>`），到头绕回；
  名字多长都放得下，不会被挤掉。名字特别长的（只有英文分类名会）真放不下时，先去掉
  箭头、再去掉右边那个 —— **中文分类永远不会碰上**。
- 当前分类**居中反白**，位置正是设置项列表里光标那一行，所以进/出分类时它不跳。
- **名称下面是这个分类的项数**（大字，居中），右下角小字 `n/N` 是第几个分类（共 N 个）。
- （v0.21 那版是上/中/下三行、项数在同一行右边；v0.22 改成一行，但页码画到了屏幕外、
  项数也没地方显示，v0.23 修好并排成上面这样。）

**81 个设置项全部可见，没有隐藏菜单了** —— 以前要开机按住 PTT + 侧键 1 才出现的
那半张菜单没有了。唯一的例外是 **DTMF 分类**，它默认不显示（那个手势现在的作用就是
把它显示出来，见下）。

| 分类 | 项数 | 里面的设置项 |
|---|---|---|
| **信道** | 19 | 模式 / 步进 / 功率 / RxDCS / RxCTCS / TxDCS / TxCTCS / TxDir / TxOffs / 宽窄带 / 存信道 / 删信道 / 信道名 / SetCfg / SetPwr / SetNFM / BzLock / Compnd / TXLock |
| **LBJ** | 8 | `LBJMSG` / `LBJPOP` / `LBJLOG` / `LBJCLR` / `LBJHST` / `LBJPRI` / `LBJLAT` / `LBJLON`（见 §6.2 / §6.3） |
| 扫描 | 6 | ChList / ScList / ScPri / PriCh1 / PriCh2 / ScnRev |
| 按键 | 9 | F1Shrt / F1Long / F2Shrt / F2Long / M Long / KeyLck / SetPTT / SetLck / 1 Call |
| 电源 | 2 | BatSav / BatTxt |
| 显示 | 11 | 信息 / ChDisp / POnMsg / BLTime / BLMin / BLMax / BLTxRx / SetCtr / 反色 / SetMet / SetGUI |
| 定时 | 4 | TxTOut / SetTOT / SetEOT / SetTmr |
| 音频 | 4 | Mic / MicBar / Beep / SetVol |
| 电台 | 6 | SQL / VOX / RxMode / Roger / STE / RP STE |
| DTMF | 6 | UPCode / DWCode / PTT ID / D ST / D Prel / D Live（**默认隐藏**） |
| 服务 | 6 | F锁 / 350 En / BatCal / BatTyp / SetNav / Reset |
| 全部 | 81 | 上面全部，按老菜单的顺序排 |

> `LBJ` 排在**第二个**，紧跟信道。

按键：

| 键 | 分类页 | 设置项列表 |
|---|---|---|
| `M` | 进入反白那个分类 | 进入这一项的取值（和以前一样） |
| `UP` / `DOWN` | 上下切换分类（循环） | 上下移动光标（循环） |
| `EXIT` | 退出菜单 | **回到分类页**；再按一次才退菜单 |
| `0`–`9` | 切到**全部**并按序号跳项 | 按序号跳项（和以前一样） |

- 每个分类各自记住上次停在哪个设置项，只记到关机为止（不写 EEPROM）。
- 取值编辑、`存信道` / `删信道`、CSS 扫描等操作和以前完全一样，只是外面多了一层分类。
- **DTMF 分类默认隐藏**：开机时按住 **PTT + 侧键 1** 不放（就是原来打开隐藏菜单的手势），
  分类页才会出现 `DTMF`，并且直接落在它上面。不按这个手势时，分类页和**全部**里都看
  不到 DTMF 分类和它那 6 项 —— 效果和以前的隐藏菜单一样，只是现在只剩这一个分类需要
  手势。

### 6.2 LBJ 的八个菜单项

菜单里和 LBJ 有关的八项（现在都在 **`LBJ` 分类**里，见上）：

| 菜单项 | 取值 | 作用 |
|---|---|---|
| **`LBJMSG`** | —（动作） | 手工打开解码窗口，显示最新一条。<br>这次开机还没解出过报文时**不打开**，菜单停在原处（挂在按键上则双响）；要看**存盘**记录用下面的 `LBJHST` |
| **`LBJHST`** | —（动作） | 直接打开**日志列表**（看 flash 里的车次记录，见 §3 / §4），不用连电脑。<br>日志为空、或正在清空时不打开 |
| **`LBJPRI`** | `--` / `1` / `2` / `3` / `4` / `5` | 哪一位是**测量点**（主位），测距就用它的坐标。`--` = 不指定（退回 APRS 那份）。<br>进这一项时光标就落在当前主位上（v0.22 起） |
| **`LBJLAT`** | 6 位数字 `DD MM hh` | 主位的**纬度**（北纬），填过的显示成 `39 54.32`（v0.22 起，见 §6.3） |
| **`LBJLON`** | 7 位数字 `DDD MM hh` | 主位的**经度**（东经），填过的显示成 `116 23.45`（v0.22 起，见 §6.3） |
| **`LBJPOP`** | `ON` / `3s` / `5s` / `10s` / `60s` | 报文**自动**打开的窗口，在最后一次报文/按键之后多久自己关掉。<br>`ON` = 不自动关（按 EXIT 或 PTT 才关）。**手工**用 `LBJMSG` / `LBJHST` 打开的窗口永远不自动关 |
| **`LBJLOG`** | `OFF` / `ON` | 每解出**一辆车**就往 flash 写一条（32 字节）。默认 `OFF`：不开就什么也不写，列表和导出都不会有数据 |
| **`LBJCLR`** | `No` / `Yes` | 清空日志。默认 `No`，只有明确选 `Yes` 才清；清空在后台按扇区慢慢擦，不卡收音 |

日志容量与行为：

- 区域 `0x018000..0x01FFFF`，**32 KiB = 1024 条 × 32 字节**。
- 写满后**从头覆盖最旧的**（环形），所以永远保存最近 1024 辆车。
- 一辆车的记录在它**最后一串报文安静 10 秒后**才落盘 —— 车刚过去时立刻看列表/导出，
  可能还差这一条。

**快捷键（v0.19 起）**：不想进菜单的话，可以把 `LBJMSG` 挂到按键上 —— 设置菜单里的
**`F1Shrt` / `F1Long` / `F2Shrt` / `F2Long` / `M Long`** 任一项（都在 **`按键` 分类**里），
动作选成 **`LBJMSG`**，之后按那个键（侧键 1 / 侧键 2 短按或长按、长按 M）就等于菜单项
`LBJMSG`：打开解码窗口显示最新一条。

- 和菜单项打开的一样是**手工打开**，**不受 `LBJPOP` 自动关闭影响**，按 EXIT 或 PTT 才关。
- 这次开机还没解出过报文时**不打开、双响**；发射中和 FM 收音机模式下同样双响拒绝。
- 在菜单/设置里按、键盘锁着按都能用（会先像 EXIT 那样退出菜单再弹窗）。
- 已存好的按键设置不会因为升级而改变，要自己把那一项选成 `LBJMSG`。

### 6.3 填自己的坐标（弹窗里的"距离"从哪来）

弹窗第 ① 行右边的**距离**，是拿**你在哪**和报文里那辆车的位置算出来的。
**v0.22 起位置直接在菜单里填，不用装任何 app。**

使用步骤（填一次就一直在，掉电不丢）：

1. 菜单 → **`LBJ`** 分类 → **`LBJPRI`** → `UP`/`DOWN` 选 **`1`**…**`5`** 中的一位
   （五位随便用，比如"家"和"单位"各占一位）→ `M` 确认。
   选 **`--`** 就是"不指定"（测距退回 §11.5 的下一顺位）。
2. **`LBJLAT`** → `M` 进输入框 → 输入**纬度 6 位**：`DD MM hh`（度 / 分 / 百分之几分），
   例：北纬 39°54.32′ 输入 `395432` → `M` 写入。
3. **`LBJLON`** → 输入**经度 7 位**：`DDD MM hh`，例：东经 116°23.45′ 输入 `1162345`
   → `M` 写入。
4. 填对了的话，按完 `M` 那一行**当场**就显示成 `39 54.32` / `116 23.45`（听到**双响**
   就是没写进去，见下面的规则）。
5. 回到主界面，等一条带详情块的报文，第 ① 行右边就有距离了。

屏幕：

```
LBJPRI           3      ← 取值区就是当前主位（-- / 1…5）
LBJLAT   39 54.32       ← 主位已填的纬度；没填过是 --
LBJLON  116 23.45       ← 经度多一位
```

按键：

| 键 | 作用 |
|---|---|
| `UP` / `DOWN` | 在 `LBJPRI` 上换一位（`--` / 1…5，循环） |
| `M` | `LBJPRI` 上 = 确认这一位；`LBJLAT` / `LBJLON` 上 = 进输入框，位数填满后再按 = **写入** |
| `0`–`9` | 输入框里写字；位数填满后**多按的数字被忽略**（要改就按 `EXIT` 退位重填） |
| `EXIT` | 输入框里 = **退掉最后一位**（退到没有才退出这一项）；没进输入框直接退出，**什么都不写** |
| `M`（还没选主位时） | `LBJLAT` / `LBJLON` 显示 `--`，按 `M` **双响**、不开输入框 |

规则：

- **按 `M` 写入成功，本行立刻显示填进去的值**（`39 54.32` / `116 23.45`），掉电不丢，
  再按一次 `M` 退出这一项。按 `M` 听到**双响** = 没写进去：位数不够、数字越界，或者
  还没选主位。（v0.22 那版按 `M` 是双响、一个字节都没写、本行还是 `--`，v0.23 修好。）
- 只支持**北纬、东经**（和 APRS Edit 一致），分辨率 0.01′ ≈ **18.5 m**，远小于弹窗显示的 0.1 km。
- **越界不写**：分 ≥ 60，或纬度超过 90°、经度超过 180°（例 `996000`、`1800001`）—— 双响，
  输入框清空重填；位数不够就按 `M` 也是双响。
- 没填过的那一半显示 `--`，不会显示成 0。
- 坐标存在固件自己的一个 **4 KiB flash 扇区**（`0x012000`，日志区和开机 logo 之间的空档）里，
  **不碰 APRS TX 的信标内容**，也不碰车次日志；写坏不了：记录是"追加 + 最后一位定稿"，
  断电只会丢掉正在写的这一条。

> 以前那个 **LBJ Edit** app 已经被固件菜单取代（见 §11），**不用再装**；装过它的电台照旧
> 读它里面那份坐标，所以原来填过的位置不会丢。

# 三、LBJ Edit（已弃用，v0.22 起）

> **不用再装它了**：坐标现在在固件菜单里填（**§6.3**）。`App/apps/lbjedit/` 还保留着、
> 还编得出来，只是不再随固件更新分发；**已经装了它的电台照旧读它里面那份坐标**
> （取值顺序见 §11.5），以前填过的位置不会丢。这一节留给已经装了它的人。

## 11. 它是什么

固件版第 ① 行右边的**距离**，需要知道**你在哪**。LBJ Edit 曾经是填这个位置的小 app：
存 **5 个位置**，选一个当 **PRIMARY**（测量点），固件版的弹窗就用它算距离
（v0.22 起固件菜单自己就能填，见 §6.3）。

> 它不是用来改 APRS 的：位置存在 app 自己的配置区，不碰 APRS TX profile 的
> 信标内容。删掉这个 app，固件版会退回去用 APRS Edit 里 TX profile 的位置。

### 11.1 屏幕

```
┌─────────────────────────────────────┐
│           LBJ EDIT                  │  标题
│ LAT 1                               │  ▶ 菜单：每个槽位一个纬度、一个经度，
│ LON 1*                    30 35.16  │    最后一项 PRIMARY
│ LAT 2                               │    "*" = 固件正在用这个槽位
│           01/11                     │  当前/总数
│ MENU=EDIT EXIT=SAVE                 │  键提示（编辑时显示输入校验结果）
└─────────────────────────────────────┘
```

### 11.2 按键

| 键 | 作用 |
|---|---|
| **UP / DOWN**（UV-K1：LEFT / RIGHT） | 选条目；停在 `PRIMARY` 时依次是 `--`（不指定）/ 1 / 2 / 3 / 4 / 5 |
| **MENU** | 打开选中的坐标进入编辑；在编辑器里再按 = **保留**这次修改 |
| **`0`–`9`** | 编辑器里：写入光标处的数字并自动前进 |
| **EXIT** | 编辑器里 = **撤销**这个字段（回到进来时的样子）；在菜单上 = **保存并退出** |

> 打开坐标时会先快照整个存储：EXIT 撤销、MENU 保留。只改过才会写 flash（只是进去看看
> 不会动任何东西）。

### 11.3 输入格式（只有北纬 / 东经）

一个槽位 = **13 位数字**：

| 字段 | 位数 | 例 | 含义 |
|---|---|---|---|
| 纬度 | 6 | `30 35 16` | 度 `DD`、分 `MM`、百分之几分 `hh` → 北纬 30°35.16′ |
| 经度 | 7 | `104 16 10` | 度 `DDD`、分 `MM`、百分之几分 `hh` → 东经 104°16.10′ |

- 分辨率 0.01′ ≈ **18.5 m**，远小于弹窗显示的 0.1 km，够用。
- 只支持**北纬、东经**（和 APRS Edit 的字段一致）。
- 没填过的槽位显示成横杠，填坏的数字（不在 0-9 / 分钟 ≥60 / 经度首位 >1）会被拒绝。

### 11.4 把哪个位置当测量点

1. 在菜单里选 **`PRIMARY`**，用 UP/DOWN 选 **1…5**。
2. 想**取消**（让固件改用 APRS TX profile 的位置）：把 `PRIMARY` 选成 **`--`**。
3. 选中的槽位会打 `*`；PRIMARY 指向没填过的槽位时，固件同样退回 APRS TX profile。

### 11.5 "距离"的取值顺序

1. **固件菜单里填的坐标**（`LBJPRI` 选中的那一位，见 §6.3）—— 填了而且合法，就用它；
2. 否则用 **LBJ Edit app 里的 PRIMARY**（v0.22 起它已弃用，只是还读得到）；
3. 否则用 **APRS Edit 里 TX profile** 的位置；
4. 都没有，或这条报文没有详情块 → 第 ① 行右侧显示 `--km`（有详情块但位置无效）或什么都不显示（没详情块）。

# 四、导出（车次日志 → CSV / Excel）

**前提**：菜单里 `LBJLOG` = `ON`，并且解出过车。

**连接线**：目前请用 **K 头写频线**（USB 转串口）。USB-C 直连的读取还有一个待修问题，
在它修好之前用 K 口。

## 12. 网页版（推荐，不用装 Python）

1. 打开页面：https://lbj.xanyi.eu.org
2. 浏览器用**桌面版 Chrome / Edge**（Web Serial）。
3. 点 **连接** → 选串口 → 点 **读取**（进度条走 32 KiB，256 × 128 字节）。
4. 读到后：表格上方有**筛选框**，**下载 CSV**（Excel 直接打开）、**下载 .bin**（原始 32 KiB 存档）。
5. 报错会直接显示在日志区（例：`错误：Read failed at 0x18000`）。

## 13. Python 版

```
python tools/lbj_log.py --list                        # 列出串口
python tools/lbj_log.py --port COM3                   # 读到终端并打印表
python tools/lbj_log.py --port COM3 -o lbj.csv        # 存 CSV（英文表头）
python tools/lbj_log.py --port COM3 --chinese -o 车次.csv   # 中文表头
python tools/lbj_log.py --port COM3 --raw zone.bin    # 只存原始 32 KiB
python tools/lbj_log.py --port COM3 --clear           # 清空日志（危险，见下）
```

| 选项 | 说明 |
|---|---|
| `--port` | 串口名，如 `COM3` / `/dev/ttyUSB0`；省略则自动选第一个 |
| `--baud` | 波特率，默认 **38400** |
| `-o/--out` | 输出 CSV 文件名（默认只打印到终端） |
| `--chinese` | CSV 表头用中文 |
| `--raw FILE` | 只把 32 KiB 原始区存成文件，不解析 |
| `--clear` | **清空**车次日志（会擦除整个区域） |
| `--list` | 列出可用串口后退出 |
| `--dry-run` | 只显示将要做什么，不真读 |
| `--debug` | 打印收发帧（排查用） |

## 14. CSV 字段

列顺序（`--chinese` 时为中文表头）：

| 列 | 中文表头 | 含义 | 未知时 |
|---|---|---|---|
| `seq` | 序号 | 记录序号（固件写入顺序，从 0 起） | — |
| `uptime_s` | 运行时间 | 写入时电台开机秒数（16 位，约 18 小时回绕） | — |
| `train` | 车次 | 车次数字（前缀 K/T/D/C 见下） | 空 |
| `direction` | 上行下行 | `DN` 下行 / `UP` 上行 | 空 |
| `speed_kmh` | 速度 | 整数，km/h | 空 |
| `km_post` | 公里标 | 一位小数，km | 空 |
| `model` | 车型 | 车型英文缩写（如 `HXD1C`） | 空 |
| `loco_number` | 车号 | 8 位机车登记号（3 位车型码 + 5 位车号） | 空 |
| `route` | 线路 | 线路名拼音首字母（如 `JHX`） | 空 |
| `distance_km` | 距离 | 一位小数，km（按接收那一刻算） | 空 |

- 车次**前缀**（K/T/D/C）来自详情块，固件在弹窗里拼在车次前；CSV 的 `train` 只有数字。
- 一行 = 一辆车（同车的短块/详块已合并）。
- 空单元格 = 这条报文没带该字段，或该码字坏了 —— 不是 0。
