# Characters the LBJRadio Chinese build carries inside the firmware image.
#
# One block of text (any line breaks, '#' starts a comment). Every character
# here gets a glyph in App/ui/cn_font.c - regenerate with:
#
#     python tools/mkcnfont.py
#
# The menu names and the popup labels are picked up from the sources
# automatically, so this file is only needed for text the firmware does not
# spell out itself: the route names an LBJ report carries (up to 4 GB2312
# characters in the detail block).
#
# It follows the same rule as the generated table: only what is actually used.
# The lines below are the trunk and regional line names Chinese railways use;
# their characters cover the names the reports carry. A character that is not
# here falls back to its pinyin initial (never a block, and no flash read), so
# a smaller list costs readability, not correctness.
#
# The list also decides the size of the image: every character is 8 bytes of
# dot matrix plus 2 bytes of index, and the 118 KiB flash region is nearly
# full. Keep it to line names.
