# UV-K1 自定义字体完整操作流程
0. 一定先导出校准数据，刷机等操作都可以在如下地址进行，https://armel.github.io/uvtools2/
1. 先刷入目录内官方编译开源固件，体验并确认界面风格是否符合自身需求
2. 配套字体文件已存放至对应目录，直接取用即可
3. 如需自制自定义字体，对照配图参数设置字体格式
4. 小字体其余参数和大字体保持一致，仅点阵尺寸改为8×8
5. 依照图片操作指引，一键生成点阵字体文件
6. 生成后的两个字体文件分别命名：16x16.fon、8x8.fon
7. 刷入目录内提供的字体专用固件
8. 打开UV-K1_FontTool.exe导入字体刷写，单次仅刷入一个字体，刷完关机后再刷第二个
9. 全部字体刷写完成，最后刷入集成自定义字体的定制版固件

## 重要风险警告
刷写开源固件后，无法完美恢复原厂固件：
即便提前备份设备校准数据，目前没有可行方案将校准数据回写至原厂固件。uvtools2网页工具仅支持把原厂校准数据迁移至F4HWN开源固件，界面显示写入成功，但并不会将校准参数恢复到原厂底层程序中。

频繁反复刷写原厂固件容易导致SPI Flash内部数据损坏，严重时设备直接变砖。
设备硬件可通过CH341编程器完整救砖修复，若无编程读写操作经验，不建议尝试刷回原厂固件。
